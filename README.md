# Orchard Harvest

Prebuilt packages for Orchard, a package manager for Apple Silicon Macs.

Every package is built by hand from its official source release and published here as a GitHub release, one per package version. Orchard's manifests point at these files and check each one by its SHA-256.

- **Platform:** Apple Silicon (arm64)
- **macOS:** each file name ends with the oldest macOS version it runs on
- **Details:** every release lists its source, how it was built and its checksum
